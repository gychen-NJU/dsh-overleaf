feat(config): default upstream to www.overleaf.com; route dynamically-inserted resources through the proxy

Per user decision the default login site is now the public Overleaf cloud;
tex.nju.edu.cn (TeXPage-based) remains usable via the settings card hot-swap
or the composed patch row.

Blank-page diagnosis for post-login TeXPage dashboards: the server-side
rewrite only covers the initial HTML, so SPAs that insert scripts/styles
at runtime with root-relative URLs dropped out of the proxy and hit the
GUI shell fallback routes.

- inject-script.ts: bridge now sweeps resource attributes on DOMContentLoaded
  and watches insertions/attribute changes via MutationObserver, rebasing any
  single-leading-slash src/href/poster/data-src under /overleaf-proxy.
- config.ts + cordis.patch.yml: DEFAULT_BASE_URL = https://www.overleaf.com.
- smoke-offline: default-fallback assertion updated; suites green.
