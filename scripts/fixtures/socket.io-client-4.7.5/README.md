# Socket.IO client regression fixture

Unmodified Socket.IO client 4.7.5 browser bundle from https://cdn.socket.io/4.7.5/socket.io.min.js. MIT license copied from https://raw.githubusercontent.com/socketio/socket.io-client/4.7.5/LICENSE. Used offline to exercise the actual URL parser and Engine.IO / Socket.IO CONNECT serialization under a synthetic desktop location. This is a test fixture, not a runtime dependency.
